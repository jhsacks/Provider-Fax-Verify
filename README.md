# Provider Fax Verify V2
Upload every file in this package to the repository root and replace the existing files. Keep the existing Render environment variables unchanged.

After Render redeploys:
1. Open the app sidebar.
2. Enter ADMIN_PASSWORD.
3. Select **Load built-in provider directory** once.

That button merges the legacy workbook directory into the existing Google Drive JSON and saves once. It preserves existing records and prevents duplicate provider/practice pairs.
